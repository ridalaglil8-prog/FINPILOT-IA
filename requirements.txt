# FinPilot AI - Python dependencies
#
# Lower bounds are the versions this app is developed and fully tested
# against (CPython 3.10, complete pytest suite). Upper bounds keep the next
# major release out.
#
# Versions are bounded RANGES rather than exact pins, on purpose: pip/uv must
# be able to pick, for the interpreter actually running the app, a release
# that ships pre-built wheels. Exact pins such as numpy==1.26.4 or
# scipy==1.13.1 have no wheels for Python 3.13 (Streamlit Community Cloud
# defaults to the newest Python), so the whole dependency install fails and
# the app boots with only Streamlit's own dependencies.
